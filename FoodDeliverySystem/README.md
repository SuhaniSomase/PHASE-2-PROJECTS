# CraveCart — Food Delivery System

A modern, responsive food delivery website built with HTML, CSS and JavaScript.

## Features

- Responsive homepage and restaurant cards
- Food search and category filters
- Price filtering and sorting by rating, popularity or price
- Add to cart, remove items and update quantities
- Dynamic subtotal, delivery fee, tax and total
- Customer details form with validation
- Demo order confirmation and order history
- LocalStorage persistence for cart and orders
- Mobile navigation menu

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run

1. Download or clone this repository.
2. Open the `FoodDeliverySystem` folder in VS Code.
3. Open `index.html` with the Live Server extension.
4. Explore the menu, add food to the cart and test checkout.

## Important Note

This is a frontend demonstration project. It does not use a real backend,
payment gateway or live restaurant service. Order information is saved
locally in the browser.

Food images load from Unsplash and require an internet connection.
